# 执行：从计划实施

## 要执行的计划

读取计划文件：`$ARGUMENTS`

## 执行说明

### 1. 阅读和理解

- 仔细阅读整个计划
- 理解所有任务及其依赖关系
- 记下要运行的验证命令
- 审查测试策略

### 2. 按顺序执行任务

对于"逐步任务"中的每个任务：

#### a. 导航到任务
- 识别所需的文件和操作
- 如需修改，先阅读相关的现有文件

#### b. 实施任务
- 严格遵循详细规范
- 与现有代码模式保持一致
- 包含适当的类型提示和文档
- 在适当的地方添加结构化日志

#### c. 逐步验证
- 每次文件更改后，检查语法
- 确保导入正确
- 验证类型正确定义

### 3. 实施测试策略

完成实施任务后：

- 创建计划中指定的所有测试文件
- 实现所有提到的测试用例
- 遵循概述的测试方法
- 确保测试覆盖边界情况

### 4. 运行验证命令

按顺序执行计划中的所有验证命令：

```bash
# 按计划中指定的方式运行每个命令
```

如果任何命令失败：
- 修复问题
- 重新运行命令
- 只有通过后才能继续

### 5. 最终验证

完成之前：

- ✅ 计划中的所有任务已完成
- ✅ 所有测试已创建并通过
- ✅ 所有验证命令通过
- ✅ 代码遵循项目规范
- ✅ 如需要，文档已添加/更新
